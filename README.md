Tor VPN Connection Checker

A lightweight desktop utility for checking whether your internet connection is using Tor or a VPN, while also looking for potential IP and DNS leaks.

The application provides a simple graphical interface with checks for:

   - Current public IP address
   - Tor exit-node detection
   - Tor over VPN status
   - VPN over Tor indicators
   - Local DNS configuration
   - Request latency
   - Detailed check results in JSON format

This tool is intended for quick diagnostics and privacy testing. 
Tor and VPN routing results are based on available network information and should be treated as indicators rather than definitive proof of the complete connection path.

Note that this checks OS configuration and not browser configuration.
